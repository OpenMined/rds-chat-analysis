# RDS Chat Analysis

## Requirements

- [just](https://github.com/casey/just?tab=readme-ov-file#installation)
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

## Setup

```bash
uv venv && uv sync
source .venv/bin/activate
cd notebooks
jupyter lab
```

## Development

```bash
pre-commit install
```
